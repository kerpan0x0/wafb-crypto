## [0.1.0] - 2026-01-03

### Added
- Initial release
- WebUSB/ADB connection management
- Device information extraction
- ADB command interface
- Package management commands
- File operations
- Logcat support
- Screenshot capture
- Structured logging system
- Comprehensive error handling
- Full test suite with high coverage
- TypeScript support
- ESM and CJS builds

### Features
- Direct USB connection without drivers
- Automatic retry on connection failures
- Battery information monitoring
- Root detection
- System properties extraction
